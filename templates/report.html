NGO Event & Campaign Management System — Summary Report

1. Project Overview

This system helps manage NGO projects, events and volunteer registrations through a web-based application using Python Flask and MySQL.

2. Volunteer Management

Volunteer details are stored in the database, and each volunteer receives an automatically generated Volunteer ID.

3. Event Management

Events can be added to the system and viewed on the Events page.

4. Community Engagement Project

The project content highlights Sevavrat Foundation's educational activities for children, including learning games, mathematics practice, basic computer awareness, drawing and creative activities.

5. Technologies Used

  • Python
  • Flask
  • MySQL
  • HTML and CSS
